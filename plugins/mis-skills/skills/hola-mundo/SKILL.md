# Hola mundo

Esta skill solo sirve para comprobar que el plugin `mis-skills` se ha instalado correctamente en este dispositivo.

Cuando se active, responde exactamente con:

> ✅ El plugin **mis-skills** está instalado y las skills se cargan correctamente.

Después indica cuántas skills del plugin `mis-skills` tienes disponibles en esta sesión y lista sus nombres.
